# Link a Separate About Us Page

## Scope
- Add a dedicated `/about` page using the About Us banner, mission image, and three workspace images already supplied.
- Keep the current contact-focused homepage unchanged.
- Connect every visible “About Us” navigation link to `/about` using the app’s built-in page navigation.

## Page structure
- Reuse the current Webgram header and footer styling for visual continuity.
- Build the About page around the previously requested sections: About banner, “Driven by Purpose, Focused on Your Growth,” and “A Creative & Collaborative Environment.”
- Preserve the desktop/tablet composition and stack content only on phone widths.
- Add unique About-page title, description, Open Graph metadata, and the existing absolute banner image for sharing.

## Validation
- Confirm `/about` opens directly and from the header link.
- Check desktop and phone layouts, all supplied images, page overflow, browser errors, and TypeScript status.
